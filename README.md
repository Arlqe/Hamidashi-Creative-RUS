# Русификатор для Hamidashi Creative (Steam)

Адаптация фанатского русификатора под лицензионную Steam-версию визуальной новеллы **Hamidashi Creative**.

## Особенности
* Полная совместимость с Steam-версией игры
* Корректная работа всех достижений Steam
* Поддержка официального дополнения (инструкция по совместимости находится в файле `README.txt` внутри архива)

## Как скачать и установить
1. Перейдите в раздел **[Releases](../../releases)** справа и скачайте архив актуальной версии.
2. Распакуйте все файлы из архива в корневую папку установленной игры с заменой.
3. Запустите игру в Steam.
